# Fancy Network V14

- Product badge is now a large transparent star-outline watermark at the top-right of the item card.
- Star outline, glow, and badge text automatically follow the `badge_color` selected in Admin.
- Supported colors remain: green, yellow/gold, orange, red, purple, blue.
- Badge preview in Admin has been removed; Admin only shows Badge Text and Badge Color controls.
- Existing Store, Admin, backend, checkout, ticket, and authentication features remain unchanged.
