# Fancy Network V11

## Store
- Product card item yang dijual tidak lagi memakai icon generik.
- Jika product punya image_url, gambar produk ditampilkan.
- Jika tidak punya gambar, card menggunakan typographic product wordmark, bukan icon fallback.
- Badge, benefit, purchase limit, harga dan CTA tetap berfungsi.

## Admin Panel
- Login admin diubah menjadi dark emerald Fancy Network control center.
- Sidebar menggunakan logo Fancy Network dan brand label.
- Dashboard, cards, tables, tabs, filters, forms, modal, ticket chat, status badges, dan responsive layout di-redesign.
- Seluruh fitur/API admin tetap sama; perubahan hanya markup visual kecil dan CSS.
