# Fancy Network V9 — Immersive Home

Homepage dirombak agar mengikuti arah visual yang disetujui: logo/crest Fancy Network berukuran besar sebagai background blur, ambient pixel/voxel glow, status rail seperti HUD, panel koneksi glass, CTA yang lebih kuat, dan shortcut dock yang terpisah dari hero.

Fitur backend/API/auth/store/support tidak diubah. `npm run dev` tetap menjalankan build + start agar tidak memakai Fast Refresh.
