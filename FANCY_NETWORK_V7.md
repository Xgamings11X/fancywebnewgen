# Fancy Network V7

Polish release focused on the issues visible in V6 screenshots:

- Home hero no longer ends with a hard clipped edge.
- Store empty-state and "Tampilkan semua" use the Fancy Network design system instead of browser defaults.
- Support login notice, empty-state, category CTAs, and form utility buttons receive explicit styling.
- Login modal rebuilt visually as a dark Fancy Network-native interface, independent from legacy orange/light theme selectors.
- Responsive modal behavior for tablet/mobile included.
- Backend, auth flow, ticket flow, store logic, and APIs are unchanged.
