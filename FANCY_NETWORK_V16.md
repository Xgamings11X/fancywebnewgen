# Fancy Network V16 — Responsive Store Grid

Responsive behavior is based on viewport width:

- <= 700px: 2 compact product cards per row.
- 701–900px: 2 medium cards per row (tablet portrait / small tablets).
- >= 901px: normal full-size product cards using the desktop grid.
- Product typography, price, buttons, benefits, star badge, and padding scale down automatically on narrow screens.
- No backend or Store logic changes.
