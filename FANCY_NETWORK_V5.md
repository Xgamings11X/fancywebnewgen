# Fancy Network V5

V5 focuses on consistency rather than copying another website.

Changes:
- Full-width dark Fancy Network canvas on every public page.
- Removes legacy white/light surfaces that leaked into Store.
- Larger, more balanced desktop content width.
- Responsive gutters and breakpoints for desktop, tablet, and mobile.
- Store hero, account panel, category rail, toolbar and product area use one dark design system.
- Home hero/server card keep the Fancy identity but scale more naturally.
- Existing backend/API/auth/store/ticket logic is unchanged.

Run on Windows:
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`
