# Fancy Network V13

Changes:
- Product badge is rendered as a transparent star watermark on the top-right of each product card.
- Badge color is taken from `badge_color` selected in Admin (green/yellow/orange/red/purple/blue).
- Admin product form now shows a live preview of the selected badge color.
- Product cards have stable dark footer/body geometry and no disconnected white section.
- Orange scrollbars are replaced globally with Fancy Network emerald/lime scrollbars.
- Admin/modal forms are hardened against horizontal overflow on narrow screens.
- All references to the previous reference brand name have been removed/replaced from source, comments, config examples, and docs.
